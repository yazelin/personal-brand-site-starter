# 各行各業要什麼

**這一份是給訪談用的。** 不同行業的受眾在意的事情差很多，
必要證據缺了，版面做得再好都沒有用。

一開始這條線做出來的範例全部是創作與技術類的人。
**多數人不是軟體工程師。** 音樂老師、房仲、花店、早餐店、學者、
教練、獸醫、水電，他們一樣需要一個形象站，而且他們的受眾問的問題完全不同。

## 怎麼用

訪談問完目的之後，翻到他那一行，把「受眾會先問的三件事」念給他聽，
問他「這三件在你的站上寫在哪裡」。**答不出來的就是要補的。**

沒有列到的行業，照同一個結構自己推：
**受眾是誰 → 他來之前最怕什麼 → 那件事要用什麼證據解掉。**

---

## 服務業與實體店

| 行業 | 受眾會先問的三件事 | 最常缺的 |
|---|---|---|
| 花店 | 你的花長什麼樣、多少錢、來得及嗎 | **當日與隔日的差別**。訂花的人多半是急的 |
| 早餐店 | 幾點開、賣什麼、在哪 | 一張清楚的營業時間。連結到地圖 |
| 咖啡店 | 有沒有位子、能不能久坐、有沒有插座 | 說清楚「適合什麼場合」，比咖啡豆產地重要 |
| 髮廊 | 誰剪、剪出來長怎樣、多少錢 | 設計師個人的作品，不是店的形象照 |
| 水電與修繕 | 你來不來我這區、多快、怎麼收費 | **服務範圍**與出勤費。沒寫等於沒有 |
| 獸醫與寵物 | 看什麼、急診時段、怎麼掛號 | 夜間與假日的規則 |

**實體店的共同點：地址、營業時間、電話要在第一屏就看得到。**
這三件被埋在頁尾是最常見的錯。

## 教學與學術

| 行業 | 受眾會先問的三件事 | 最常缺的 |
|---|---|---|
| 音樂老師 | 教什麼程度、一堂多少、在哪上 | **一段你的演奏或學生的成果**。文字說服不了 |
| 家教與補習 | 幾個人一班、上課時間、成效 | 班級人數。家長第一個問這個 |
| 學術與研究 | 你研究什麼、發表了什麼、怎麼找你 | 一句話講清楚研究主題，不要只放論文清單 |
| 教練與訓練 | 適合誰、多久看得到、要花多少 | 「不適合誰」。寫出來反而更可信 |
| 講師與內訓 | 講什麼、形式、檔期 | 課程模組與人數上限 |

**教學類的共同點：受眾要的是「我這種程度可以嗎」。**
先寫程度與適合的人，再寫你的資歷。

## 仲介與顧問

| 行業 | 受眾會先問的三件事 | 最常缺的 |
|---|---|---|
| 房仲 | 你熟哪一區、成交過什麼、怎麼收費 | **只熟一兩區反而更好賣**。什麼都做等於什麼都不專 |
| 保險與理財 | 你賣誰家的、怎麼賺錢、會不會一直打給我 | 收費方式。講清楚反而降低戒心 |
| 記帳與報稅 | 我這種規模你接嗎、多少錢、什麼時候要給資料 | 適合的客戶規模 |
| 律師與代書 | 你辦哪一類、大概多少、要多久 | 案件類型的邊界 |

**這一類的共同點：受眾怕被推銷。** 把收費方式與邊界先寫清楚，
比任何專業形容詞有用。

## 創作與技術

| 行業 | 受眾會先問的三件事 | 最常缺的 |
|---|---|---|
| 攝影 | 拍出來長怎樣、多少錢、檔期 | **照片**。這一行沒有照片等於沒有站 |
| 插畫與設計 | 風格、接什麼、多少錢 | 作品要能點進去看大圖 |
| 音樂與配樂 | 聽起來怎樣、接什麼、多久 | 一段可以直接播的音檔 |
| 工程與開發 | 你做過什麼、負責哪一段、怎麼合作 | 每件作品你負責哪一段 |
| 寫作與文案 | 你寫過什麼、改法長怎樣、多少錢 | 改前改後的對照 |

## 一件所有行業都一樣的事

受眾審查跑了很多輪，**最常出現的阻斷永遠是同一個：沒有價格線索**。
原話是「我預算有限，怕太貴不敢問，浪費彼此時間」。

不想公開報價的人，至少給一個區間、起跳價、或是「大概落在什麼帶」。
`skills/05-optimise/SKILL.md` 的分數表裡，第 4 項「我想知道的事情這頁都寫了」
分數低的時候，八成就是這個。

## 外部參考

小型商家網站的共通要件，幾份清單講的其實是同一件事：
第一屏就要看得懂你是誰、做什麼、給誰，聯絡方式三秒內找得到，
還要有別人講你好話的痕跡。

- [美國中小企業署：五個必要頁面](https://www.sba.gov/blog/5-essential-pages-your-small-business-website)
- [美國商會：網站上要放什麼才會成交](https://www.uschamber.com/co/run/technology/what-to-include-on-business-websites)
- [小型商家網站要件清單](https://studiomesa.co/articles/small-business-website-features-checklist/)

**但那些清單只講「要有什麼」，不會告訴你「你這一行的人在怕什麼」。**
那一段要靠訪談問，靠階段五的受眾審查驗。
