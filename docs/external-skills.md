## 沒找到的東西

寫這份清單的時候（2026 年 8 月）在 GitHub 上找過，
沒有任何一支 skill 是從訪談開始、一路帶到選後端與上線的。
現有的都停在「幫你寫 landing page 文案」或「幫你檢查現有的頁面」。
中間那一段就是這個 repo 在做的事。
